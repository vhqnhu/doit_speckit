## Summary

Build the initial `doit` goal tracking dashboard as a client-side Next.js app. The page presents current goals and completed goals in responsive columns, persists goals in browser localStorage, uses Tailwind CSS v4 `@theme` tokens for a modern light pastel palette, uses shadcn UI components for accessible controls and modal behavior, and uses date-fns for date formatting and whole-day deadline calculations.

## Technical Context

**Language/Version**: TypeScript `^5`, React `19.2.8`, Next.js `16.3.3`

**Primary Dependencies**: Next.js App Router, React, Tailwind CSS `^4` with `@theme`, shadcn UI components, date-fns

**Storage**: Browser localStorage using versioned key `doit.goals.v1`

**Testing**: N/A - no unit, integration, or e2e tests per constitution; use manual verification, ESLint, and TypeScript checks only

**Target Platform**: Modern browsers served by Next.js

**Project Type**: Single-page web application within Next.js App Router

**Performance Goals**: Initial dashboard interaction responds immediately for typical personal goal lists; create/complete/delete updates should be visible in under 100 ms on supported browsers

**Constraints**: Client-only persistence, no authentication, no server API, no automated tests, responsive mobile/desktop layout, delete without confirmation, fixed sorting rules

**Scale/Scope**: One dashboard screen, one add-goal modal, one localStorage-backed goal collection for a single browser profile
